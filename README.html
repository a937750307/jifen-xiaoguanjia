积分小管家

面向家庭和班级的轻量级积分管理工具

功能特点

双模式支持

  • 家长模式：以家庭为单位，记录孩子的日常行为积分
  • 教师模式：以班级为单位，记录学生的课堂表现积分
  • 不同模式拥有独立的主题色、默认积分项和成员数据

多成员管理

  • 支持添加多个成员，可为每个成员设置分组（如班级、科目等）
  • 成员管理列表按分组聚合显示，支持分组筛选和排序
  • 分组支持折叠/展开，方便管理大量成员
  • 顶部成员栏可快速切换当前成员

积分记录

  • 赚取积分：记录积极行为，如完成作业、课堂表现等
  • 扣除积分：记录不良行为，如未交作业、迟到等
  • 积分清空：清空当前成员积分并生成记录，可通过撤销恢复
  • 系统重置：支持重置参数项、重置当前成员或重置全部成员

积分兑换

  • 内置多种奖励兑换项，家长和教师模式各有不同的兑换项
  • 兑换后自动扣除积分并生成记录

数据管理

  • 导入/导出：支持数据的导入和导出
  • 密码保护：可设置密码保护数据
  • 数据保存在浏览器本地，无需服务器

文件结构

  • index.html：页面结构
  • style.css：样式文件
  • script.js：交互逻辑
  • README.md / README.html：项目说明

使用方法

  1. 直接在浏览器中打开 index.html 文件
  2. 选择「家长模式」或「教师模式」
  3. 添加成员，设置分组（可选）
  4. 通过首页入口进行赚取积分、扣除积分或奖励兑换
  5. 在「积分记录」中查看历史记录，可撤销误操作

浏览器支持

  • Chrome / Edge / Safari / Firefox 等现代浏览器
  • 推荐在移动端浏览器中使用
  • 数据存储依赖浏览器 localStorage
